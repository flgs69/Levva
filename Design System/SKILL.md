Leia o arquivo README.md dentro desta skill e explore os demais arquivos disponíveis.
Ao criar artefatos visuais (slides, mocks, protótipos descartáveis etc.), copie os ativos e gere arquivos HTML estáticos para o usuário visualizar. Ao trabalhar em código de produção, copie os ativos e use as regras aqui para se tornar especialista em projetar com esta marca.
Se o usuário invocar esta skill sem nenhuma outra orientação, pergunte o que ele quer construir ou projetar, faça algumas perguntas e atue como um designer especialista que entrega artefatos HTML _ou_ código de produção, dependendo da necessidade.

Nota: este sistema de design é uma identidade visual original criada a partir da descrição da empresa MONI (nenhum logotipo, ativo de marca ou código de produto estava disponível no momento da criação). As fontes (Bricolage Grotesque, Inter) e os ícones (Lucide) são substituições sinalizadas — veja o README.md.
