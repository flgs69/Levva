Botão em pílula para chamadas de ação em quatro variantes chapadas (primary/secondary/outline/ghost); use `primary` (coral) para a ação principal de cada tela, `secondary` (tinta) para a próxima ação mais importante, `outline`/`ghost` para ações de menor destaque.

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Iniciar uma campanha</Button>
```

Variantes: `primary`, `secondary`, `outline`, `ghost`. Tamanhos: `sm`, `md`, `lg`. Passe `icon` para um ícone à esquerda. `disabled` esmaece e bloqueia cliques.
