Botão quadrado somente com ícone (ações de barra de ferramentas, linhas de tabela, fechar/voltar).

```jsx
<IconButton icon={<XIcon />} label="Fechar" onClick={() => {}} />
```

Variantes: `solid` (preenchido em tinta), `outline` (com borda). Tamanhos: `sm`, `md`, `lg`. Sempre passe `label` para acessibilidade.
