Container base: borda de tinta + sombra chapada deslocada (estilo pôster, não um brilho suave). Use para painéis de dashboard, linhas de lista, cartões de recompensa no app.

```jsx
<Card><h3>Desempenho da campanha</h3></Card>
```

Defina `flat={false}` para uma sombra ambiente mais suave em superfícies densas de dados (tabelas, modais).
