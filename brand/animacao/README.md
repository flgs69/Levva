# Movimento

- `levva-logo-animation-light.mp4`: animação da logo sobre papel, 1920 x 1080, 60 fps, 3,4 s.
- `levva-logo-animation-dark.mp4`: a mesma sobre tinta, com a assinatura negativa.
- `levva-lockup-animated.svg`: assinatura animada em SVG com CSS, toca uma vez. Respeita "reduzir movimento".

Roteiro: cantos entram (0 a 520 ms), ponto acende (380 a 720 ms), letras sobem (560 a 1300 ms), ponto final acende (1320 a 1660 ms), ponto do símbolo pisca duas vezes (900 a 2100 ms). Curva ease-snap.
