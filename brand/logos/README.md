# Logos

- `levva-mark.svg` — O símbolo: dois chevrons para cima num quadrado de cantos 16/64. Cores fixas: fundo levva `#0B6E4F`, chevron de cima lift `#FFB627`, de baixo `#FFFFFF`. Ícone de app, avatar, favicon. Mínimo 24px.
- `levva-wordmark.svg` — A palavra "levva" em traço único, tinta ink `#0F1F19`. Para fundos claros (surface, surface-raised, levva-soft). Mínimo 64px de largura.
- `levva-wordmark-reverse.svg` — A mesma palavra em branco `#FFFFFF`. Só sobre ink ou levva.
- `levva-lockup.svg` — Símbolo + palavra, a assinatura principal. Para fundos claros. Mínimo 96px de largura.

Área de proteção: em volta de qualquer versão, deixe livre metade da altura do símbolo. Não recolorir, não girar, não aplicar sombra nem contorno.
